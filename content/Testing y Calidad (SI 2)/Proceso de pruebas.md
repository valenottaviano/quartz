# Proceso de pruebas

%%
Date:: [[2025-09-04]]
Course:: [[Testing y Calidad]]
Source:: [[]]
%%

- Conjunto de actividades de verificación y validación que se realizan a lo largo del desarrollo o adaptación de un sistema, para asegurar que el software desarrollado o adquirido alcanza los resultados requeridos
	- Las pruebas se realizan a lo largo de todo el ciclo de vida (incluyendo cuando se realizan modificaciones).
	- No solo lo que desarrolla mi organización, sino también cuando adquiero un software de terceros.

### Por qué es necesario un proceso?
- No puedo sentarme con el software y probar?
	- Las tareas deben poder ser reproducible. Cómo lo reporto a los programadores si no se puede replicar?
- Establece las bases para implementar mejoras continuas sobre el mismo.
- Me permite saber si he mejorado o no en una funcionalidad. Puedo comparar.
