# Pruebas Happy Path

%%
Date:: [[2025-09-25]]
Course:: [[Testing y Calidad]]
Source:: [[Técnicas de Diseño de Testing]]
%%




Son un tipo de prueba de software que se centran en validar el comportamiento del sistema bajo condiciones ideales y esperadas. En otras palabras, las pruebas "HP" se enfocan en verificar que es sistema funciones correctamente cuando se utilizan entradas válidas y todo sigue el flujo previsto, sin desviaciones o errores imprevistos.
- **Flujo esperado**
	- Evalúan el escenario en el que el usuario sigue los pasos correctos sin desviarse de lo que se anticipa como comportamiento normal. 
	- No se contemplan errores ni condiciones adicionales.
- **Condiciones ideales**
	- Se prueban con entradas válidas y predecibles que cumplen con todos los requisitos y no generan situaciones fuera del control del sistema.

-  Objetivo
	- Verificar que el sistema funciona conforma a las especificaciones, sin explorar casos extremos, entradas no validas, o escenarios inusuales
- Velocidad
	- Suelen ser rápidas ya que no contemplan caminos alternativos ni manejos complejos de errores.
