# Representaciones del modelo CMMI

%%
Date:: [[2025-03-26]]
Course:: [[Ingeniería de Software II]]
Source:: [[CMMI - Capability Maturity Model Integration]]
%%

El modelo CMMI ofrece **dos formas de representar la mejora de procesos** dentro de una organización: la **representación continua** y la **representación por niveles**. Ambas comparten el mismo contenido base (áreas de proceso, prácticas específicas y genéricas), pero difieren en cómo se evalúa y se guía la mejora.

### Representación continua

- Se centra en **mejorar procesos específicos** de forma individual.
- Cada área de proceso (por ejemplo, gestión de proyectos, verificación, validación) se evalúa y mejora **por separado**.
- Permite asignar **niveles de capacidad** a cada proceso (de 0 a 5).
- Es ideal para organizaciones que desean enfocar sus esfuerzos en **procesos clave** sin necesidad de abordar todo el modelo.

### Representación por niveles

- Agrupa los procesos en **niveles de madurez** organizacional, del 1 al 5.
- Cada nivel incluye un conjunto predefinido de áreas de proceso que deben estar implementadas.
- Requiere una **adopción progresiva y estructurada** del modelo.
- Es la representación más común para organizaciones que buscan **certificación formal** o una evaluación global de su madurez.
